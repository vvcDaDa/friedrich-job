# Friedrich 打工记

一个关于网络诈骗、打工还债与重新出发的网页小游戏。纯静态 HTML / CSS / JavaScript，无需构建，可直接部署到 GitHub Pages。

## 游戏内容

- **序章**：Friedrich 收到一条「点赞兼职」私信，一步步落入刷单返利骗局，最终被骗 ¥18,525（含 ¥6,000 网贷）。是否报警会影响后续剧情。
- **14 天打工**：每天分白天 / 晚上两个时段，可以打工、休息或散心。第 7 天交房租，第 14 天还清网贷。
- **5 种打工小游戏**：🧋 奶茶店 · 📄 发传单 · 🏪 便利店夜班（找零）· 🛵 外卖骑手（地图配送）· 📚 德语家教（单词测验）。也可以「随便干干」直接跳过。
- **夜间事件**：反诈识别测验、妈妈来电、二次诈骗、暴力催收、捡到钱包……
- **3 种结局 + 8 个成就**，并附反诈小贴士。

操作：鼠标 / 触屏均可；奶茶店、外卖、家教支持键盘快捷键。进度自动保存在浏览器本地。

## 本地运行

```bash
python3 -m http.server 8000
```


## 目录结构

```
index.html

js/minigames.js   5 个打工小游戏
js/events.js      夜间事件
js/game.js        主流程与结局
```
